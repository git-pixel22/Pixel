# Pixel

## 🔍 AI-Assisted Code Quality (CodeRabbit)

Pixel uses **CodeRabbit** to automatically review every pull request.  
This ensures:

- high code quality  
- consistency across frontend + backend  
- architectural correctness  
- security best practices  
- clean, readable, maintainable code  

### Every PR triggers:

- automated review  
- inline suggestions  
- optional change requests  
- summary of improvements
